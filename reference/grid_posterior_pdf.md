# Density of a grid posterior

Density of a grid posterior

## Usage

``` r
grid_posterior_pdf(posterior, x)
```

## Arguments

- posterior:

  Output of
  [`grid_posterior()`](https://tristanfauvel.github.io/BExTE/reference/grid_posterior.md).

- x:

  Points at which to evaluate it.

## Value

The density at `x`.
