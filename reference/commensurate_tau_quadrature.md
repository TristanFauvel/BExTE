# Quadrature rule for the commensurability parameter

Quadrature rule for the commensurability parameter

## Usage

``` r
commensurate_tau_quadrature(model, n_nodes)
```

## Arguments

- model:

  A
  [GaussianCommensuratePowerPrior](https://tristanfauvel.github.io/BExTE/reference/GaussianCommensuratePowerPrior.md)
  object.

- n_nodes:

  Number of nodes.

## Value

A list with `tau`, `inverse_tau`, `log_tau` and `weights`.
