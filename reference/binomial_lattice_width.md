# Prior density of the risk difference given both control rates, on the lattice

1 / (N - \|i - j\|), the N x N matrix every binomial power prior
integrates the control rates against; kept per worker.

## Usage

``` r
binomial_lattice_width(n_lattice)
```

## Arguments

- n_lattice:

  Number of lattice points N.

## Value

An N x N matrix.
