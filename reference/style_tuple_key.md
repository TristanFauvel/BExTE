# A tuple of parameter values as a lookup key

Rounded to the two decimals
[`make_labels_from_parameters()`](https://quinten-health-os.github.io/BayesianExtrapolationSimulation/reference/make_labels_from_parameters.md)
rounds to, so a configured value and the number parsed back out of its
label agree despite floating point.

## Usage

``` r
style_tuple_key(values)
```

## Arguments

- values:

  A numeric vector.

## Value

A single string.
