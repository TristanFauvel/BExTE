# Predicates used to check a column against a declared type

The vocabulary
[`check_colnames()`](https://tristanfauvel.github.io/BExTE/reference/check_colnames.md)
accepts in its `types` argument. `numeric` deliberately accepts integer
columns, since sample sizes and replicate counts are read back as
either.

## Usage

``` r
column_type_predicates
```
