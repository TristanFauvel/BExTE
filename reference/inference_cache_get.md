# Read one analysis from the cache

Read one analysis from the cache

## Usage

``` r
inference_cache_get(key)
```

## Arguments

- key:

  Key returned by
  [`inference_cache_key()`](https://quinten-health-os.github.io/BayesianExtrapolationSimulation/reference/inference_cache_key.md).

## Value

The stored analysis, or `NULL`.
