# Store of binomial target terms, by target likelihoods

Holds up to
[`binomial_target_terms_limit()`](https://tristanfauvel.github.io/BExTE/reference/binomial_target_terms_limit.md)
matrices of target terms in `entries`; see
[`binomial_target_terms()`](https://tristanfauvel.github.io/BExTE/reference/binomial_target_terms.md).

## Usage

``` r
binomial_target_terms_store
```
