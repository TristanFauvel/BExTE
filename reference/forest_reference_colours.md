# The colours of the forest plots' reference lines, defaulting to the literal values the publication figures use so that `palette = NULL` output is untouched.

The colours of the forest plots' reference lines, defaulting to the
literal values the publication figures use so that `palette = NULL`
output is untouched.

## Usage

``` r
forest_reference_colours(palette)
```

## Arguments

- palette:

  A colour scheme from bexte_palette(), or NULL.

## Value

A list with `target`, `source` and `ink` colours.
