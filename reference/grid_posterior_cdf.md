# Distribution function of a grid posterior

Distribution function of a grid posterior

## Usage

``` r
grid_posterior_cdf(posterior, x)
```

## Arguments

- posterior:

  Output of
  [`grid_posterior()`](https://quinten-health-os.github.io/BayesianExtrapolationSimulation/reference/grid_posterior.md).

- x:

  Points at which to evaluate it.

## Value

The distribution function at `x`.
