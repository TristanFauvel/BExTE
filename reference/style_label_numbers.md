# Numbers a parameter label assigns to its parameters

Only numbers introduced by "=" count. A notation such as the initial
prior's carries a digit of its own (pi nought) that has nothing to do
with the value the parameter took.

## Usage

``` r
style_label_numbers(label)
```

## Arguments

- label:

  A parameter label, as plain text.

## Value

The numbers in the order they appear, possibly none.
