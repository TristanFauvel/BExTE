# Fixed shape and hue for a method

Fixed shape and hue for a method

## Usage

``` r
method_style(method, styles = methods_style, labels = style_methods_labels())
```

## Arguments

- method:

  A method key or display label.

- styles:

  The style table, from conf/methods_plots_config.R.

- labels:

  The method label table, used to resolve a display label.

## Value

A list with `shape` and `hue`.
