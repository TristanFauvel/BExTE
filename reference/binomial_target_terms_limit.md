# Number of target terms matrices kept per process

Set by the option `BExTE.target_terms_cache`, 0 (none) by default; see
[`binomial_target_terms()`](https://tristanfauvel.github.io/BExTE/reference/binomial_target_terms.md).

## Usage

``` r
binomial_target_terms_limit()
```

## Value

The number of matrices.
