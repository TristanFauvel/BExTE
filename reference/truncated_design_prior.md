# A design prior truncated to an interval and renormalised

A design prior truncated to an interval and renormalised

## Usage

``` r
truncated_design_prior(design_prior, lower, upper)
```

## Arguments

- design_prior:

  The design prior to truncate.

- lower, upper:

  The interval.

## Value

A
[FunctionalDesignPrior](https://tristanfauvel.github.io/BExTE/reference/FunctionalDesignPrior.md).
