# Total target-study sample sizes considered for each case study (table S1)

Total target-study sample sizes considered for each case study (table
S1)

## Usage

``` r
table_target_sample_sizes(
  case_studies,
  sample_size_factors,
  case_studies_config_dir,
  tables_dir
)
```

## Arguments

- case_studies:

  Character vector of case study names.

- sample_size_factors:

  Numeric vector of sample size factors.

- case_studies_config_dir:

  Directory holding the case study YAMLs.

- tables_dir:

  Directory to write into.

## Value

The path of the written `.tex` file.
