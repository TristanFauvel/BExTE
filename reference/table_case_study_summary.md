# Summary of the clinical case studies (table S7)

Summary of the clinical case studies (table S7)

## Usage

``` r
table_case_study_summary(case_studies, case_studies_config_dir, tables_dir)
```

## Arguments

- case_studies:

  Character vector of case study names.

- case_studies_config_dir:

  Directory holding the case study YAMLs.

- tables_dir:

  Directory to write into.

## Value

The path of the written `.tex` file.
