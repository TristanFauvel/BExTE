# Store one analysis in the cache

Store one analysis in the cache

## Usage

``` r
inference_cache_set(key, value)
```

## Arguments

- key:

  Key returned by
  [`inference_cache_key()`](https://tristanfauvel.github.io/BExTE/reference/inference_cache_key.md).

- value:

  The analysis to store.

## Value

`NULL`, invisibly.
